# Animate Solid the way Motion does.

solid-motion mirrors the `motion/react` components on Solid 2. Every manual page
runs each demo in both libraries, with the same controls.

```sh
npm install @totallynotdavid/solid-motion solid-js@next @solidjs/web@next
```
