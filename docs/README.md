# Manual

Each page has an example you can run. Start with the first one.

1. [Animating elements](animating-elements.md): `motion.*`, targets, layers,
   callbacks, animation controls.
2. [Gestures](gestures.md): hover, tap, focus, pan and in-view states, and
   `createInView`.
3. [Drag](drag.md): `drag`, constraints, momentum and `createDragControls`.
4. [Reorder](reorder.md): `Reorder.Group` and `Reorder.Item`.
5. [Variants](variants.md): named targets, stagger and ordering.
6. [Presence](presence.md): exit animations with `AnimatePresence` and
   `AnimatePresenceList`.
7. [Motion values](motion-values.md): `createMotionValue`, `createTransform`,
   `createVelocity`, `createTime` and `createWillChange`.
8. [Scroll](scroll.md): `createScroll` and offsets.
9. [Layout](layout.md): `layout`, `layoutId` and `LayoutGroup`.
10. [SVG](svg.md): geometry and path drawing.
11. [Configuration](configuration.md): `MotionConfig`, reduced motion and
    `useReducedMotion`.
12. [createMotion and custom components](create-motion.md): animate an element
    you render yourself.
13. [createAnimate](create-animate.md): animate elements you do not render.
14. [Architecture](architecture.md): what each source file does.
