# Manual

Each page has an example you can run. Start with the first one.

1. [Animating elements](animating-elements.md): `motion.*`, targets, layers,
   callbacks.
2. [Gestures](gestures.md): hover, press, focus and in-view states, and
   `createInView`.
3. [Variants](variants.md): named targets, stagger and ordering.
4. [Presence](presence.md): exit animations with `AnimatePresence` and
   `AnimatePresenceList`.
5. [Motion values](motion-values.md): `createMotionValue`, `transform`,
   `createVelocity`, `createTime` and `createWillChange`.
6. [Scroll](scroll.md): `createScroll`.
7. [Layout](layout.md): `layout` and `layoutId`.
8. [SVG](svg.md): geometry and path drawing.
9. [Configuration](configuration.md): `MotionConfig`, reduced motion and
   `useReducedMotion`.
10. [createMotion and custom components](create-motion.md): animate an element
    you render yourself.
11. [createAnimate](create-animate.md): animate elements you do not render.
12. [Architecture](architecture.md): what each source file does.
